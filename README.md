# 影之刃零 · 武典

《影之刃零》（Phantom Blade Zero，2026-10-29 发售）全流程攻略站。单页水墨武侠风格，纯静态、零依赖、零后端。

## 直接查看

双击根目录的 `index.html` 即可打开（不依赖模块加载或网络请求；在线字体加载失败会自动降级到本地宋体/楷体）。

也可以起个本地服务：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

部署到 Cloudflare 仍是纯静态资源：

```bash
npx wrangler deploy
```

## 交互

- 开卷刀光 / 印章动画、逐字标题、打字机卷首语、数字滚动、落花粒子、滚动视差与渐显
- Boss / 章节 / 异闻 / 警示手风琴展开；群雄谱口径切换（75 条首领录 / 61 场遭遇），两套清单各自支持章节或区域 + 类别双筛选、编号 / 中文名 / 英文名 / 掉落搜索（按 `/` 聚焦），顶部显示筛选与勾选计数
- 首领录每条可一键跳到「按遭遇」视图并自动展开对应配装详解
- 结局自检器：拨动「湖心秘密」「血脉觉醒」两个开关，实时显示终局分支
- 收集清单、兵谱、奖杯、章节、75 条首领录、61 场遭遇均可勾选，进度写入浏览器 `localStorage`，顶栏进度环与行囊抽屉实时汇总（6 项统计）
- 键盘：`/` 聚焦搜索、`Esc` 关闭抽屉；适配移动端与 `prefers-reduced-motion`

## 说明

- 项目已移除原先的 Cloudflare Workers + D1 演示后端（`/api/tips`、`/api/server-info`、搜索框 Demo），不再需要数据库或服务端。
- 攻略内容整理自游民星空（含 61 页全 BOSS 打法指南）、游侠网、17173、18183、IGN Wiki、Game8、Rock Paper Shotgun、GameRant、PCGamesN、Fextralife、KeenGamer、gam3s.gg、PSNINE、phantombladezero.th.gl、All Things How、小黑盒 App 及多个中文攻略号。
- **Boss 计数四种口径**：游戏内「BOSS 战绩」按血条称号计 **75 条**（小黑盒 App，本页首领录采用）；游戏数据站 th.gl 与 All Things How 各列 74 条，前者单列「断魂山 ·「组织」冥主：左殇（银发）」、后者单列「三张脸的诡异魔偶」，并集恰为 75；按玩家实际遭遇计 **61 场**（Rock Paper Shotgun 实测全清，本页遭遇视图采用）；只算主线必打 31 场（Game8，另记总计 62 场）。差异来自多称号形态：白赤练 2 条、玉琮 4 条、左殇 3 条、沐小葵与双护卫 4 条，金面人四次龙柱试炼合 1 条战绩却拆 4 场遭遇。
- 18 场标「详解」的是逐阶段拆解；43 场标「简目」的是该区域通用配装 + 已确认机制要点。「三张脸的诡异魔偶」与「卅四号·混沌魔偶：「玉琮」」可能为同一场战斗的两个血条标题，页面已标注存疑。
- **术语校订（2026-11-11）**：75 条首领录中文名逐条对照游民《全收集列表 · Boss》官方写法；系统术语对照 Bilibili 游戏 Wiki「战斗系统 / 铃铛」与官网用词。已修正「组织影主 →「组织」冥主」「帷帽使者 → 梦差」「魂断山 → 断魂山」「铜锤长杵 → 长柄金瓜（去重）」「不竭 → 不尽水（秘药）」「奇术 → 奇门」「精确格挡 → 完美格挡」「影之武装消耗杀气 → 消耗暗源」「破防＝处决 → 两者不同」「逆天者 HP → 破局者 HP」等。仍无法确认中文正式名的英文直译掉落名已单列在「拾 · 术语与口径」，不冒充官方译名。
