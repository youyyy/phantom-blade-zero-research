# 影之刃零 · 武典

《影之刃零》（Phantom Blade Zero，2026-10-29 发售）全流程攻略站。单页水墨武侠风格，纯静态、零依赖、零后端。

## 直接查看

双击根目录的 `index.html` 即可打开（不依赖模块加载或网络请求；在线字体加载失败会自动降级到本地宋体/楷体）。

也可以起个本地服务：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

部署到 Cloudflare 仍是纯静态资源：

```bash
npx wrangler deploy
```

## 交互

- 开卷刀光 / 印章动画、逐字标题、打字机卷首语、数字滚动、落花粒子、滚动视差与渐显
- Boss / 章节 / 异闻 / 警示手风琴展开；Boss 支持区域 + 类别双筛选、编号 / 中文名 / 英文名 / 掉落搜索（按 `/` 聚焦），顶部显示筛选与讨伐计数
- 结局自检器：拨动「湖心秘密」「血脉觉醒」两个开关，实时显示终局分支
- 收集清单、兵谱、奖杯、章节、61 场首领讨伐均可勾选，进度写入浏览器 `localStorage`，顶栏进度环与行囊抽屉实时汇总
- 键盘：`/` 聚焦搜索、`Esc` 关闭抽屉；适配移动端与 `prefers-reduced-motion`

## 说明

- 项目已移除原先的 Cloudflare Workers + D1 演示后端（`/api/tips`、`/api/server-info`、搜索框 Demo），不再需要数据库或服务端。
- 攻略内容整理自游民星空（含 61 页全 BOSS 打法指南）、游侠网、17173、18183、IGN Wiki、Game8、Rock Paper Shotgun、GameRant、PCGamesN、Fextralife、KeenGamer、gam3s.gg、PSNINE 及多个中文攻略号。
- Boss 计数口径：主线必打 31 场（Game8）；含可选 / 隐藏 / 小首领 / 重复遭遇共 61 场（Rock Paper Shotgun 实测清单，本页采用），Game8 另记 62 场。本页把沐小葵与双护卫合并为一场，故主线类 30 场；金面人四次龙柱试炼、追命两度交手、游龙二番战均单独计场。类别筛选按 Game8 的主线 / 可选划分标注。
- 18 场标「详解」的是逐阶段拆解；43 场标「简目」的是该区域通用配装 + 已确认机制要点，部分掉落名按英文社区资料直译。发售后的社区资料在译名与数量上仍有差异，页面「来源与存疑」一节已列出，**一切以游戏内图鉴与任务日志为准**。
- 2026-11-11 修订版。
